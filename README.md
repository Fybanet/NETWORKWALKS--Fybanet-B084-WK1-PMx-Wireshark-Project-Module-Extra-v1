## Lab 03 — Identify the Attacker's IP

<kbd>Network Reconnaissance & Port Scanning Analysis</kbd>

### Objective

Investigate suspicious network traffic directed towards a company web server to identify potential reconnaissance activity and understand how an attacker might probe a target system for accessible services.

### Scenario

A staff member reports unusual network traffic directed towards the company's web server.

Acting as a SOC analyst, the task involved capturing network packets, investigating connection attempts, examining source and destination information, and determining the nature of the suspicious activity.

### Investigation Activities

- Captured live network traffic using Wireshark.
- Examined TCP connection establishment packets.
- Investigated SYN packet patterns.
- Examined source and destination addresses.
- Analyzed TCP conversations and connection attempts.
- Differentiated between successful and unsuccessful connection attempts.
- Investigated indicators associated with port scanning.

### Skills Demonstrated

- TCP packet analysis.
- Network reconnaissance detection.
- Port scanning identification.
- Source and destination analysis.
- SOC threat investigation.
